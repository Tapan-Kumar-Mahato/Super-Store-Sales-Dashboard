# Super-Store-Sales-Dashboard
📊 Super Store Sales Dashboard
📌 Overview

The Super Store Sales Dashboard is a data visualization project designed to analyze and present sales performance of a retail store. It provides meaningful insights into sales trends, customer behavior, and product performance using interactive visuals.

This dashboard helps businesses make data-driven decisions by identifying key growth areas and potential issues.

🎯 Objectives
Analyze overall sales and profit performance
Identify top-performing products and categories
Track regional sales distribution
Understand customer purchasing patterns
Visualize trends over time
📂 Dataset

The dataset used in this project contains retail sales data, including:

Order ID
Order Date
Customer Name
Region
Category & Sub-Category
Sales
Quantity
Profit
🛠️ Tools & Technologies
Power BI (for dashboard creation)
Microsoft Excel / CSV (data source)
Data Cleaning & Transformation (Power Query)
📈 Dashboard Features
📅 Time-based Analysis (Monthly/Yearly Sales Trends)
🌍 Region-wise Sales Distribution
🛍️ Category & Sub-category Insights
💰 Profit vs Sales Comparison
👥 Customer Segment Analysis
🔍 Interactive filters and slicers
📊 Key Insights
Identifies high and low performing regions
Highlights most profitable product categories
Detects seasonal sales patterns
Helps in optimizing inventory and marketing strategies
🚀 How to Use
Open the .pbix file in Power BI Desktop
Load or refresh the dataset if required
Use filters and slicers to explore insights
Analyze trends and make business decisions
